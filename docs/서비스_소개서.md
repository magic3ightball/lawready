# LawReady 서비스 소개서

> 제품은 만들었지만, 해외 개인정보 문서가 막막한 창업자를 돕습니다.

서비스 자료를 전달하면 국가별 개인정보처리방침 초안을 만들고, 고객과 전문가가 확인해야 할 부분을 구분해 주며, 변경 이력까지 관리하는 서비스입니다.

> **한 문장으로 말하면**
>
> LawReady는 사용자가 지정한 웹페이지·PRD·서비스 설명 등에서 개인정보 처리 사실을 정리하고, 작성 시점의 국가별 법령과 공식 지침을 참고해 국가별 개인정보처리방침 초안을 만듭니다.

- 첫 고객: 국내 소프트웨어 창업자
- 초기 지원: 대한민국·캘리포니아·일본·싱가포르
- 문서 버전: SVI-2026-08-v1.5

## 01. 누가, 왜 쓰는가

법무팀 없이 해외 출시를 준비하는 개인 예비창업자와 국내 소프트웨어 창업기업이 첫 고객입니다.

| 지금은 | 이 서비스를 쓰면 |
|---|---|
| 나라별 법이 다르고, 인터넷 템플릿이 내 서비스에 맞는지 알 수 없습니다. | 내 서비스가 실제로 처리하는 개인정보를 기준으로 국가별 문서를 만듭니다. |
| 변호사를 국가마다 반복해서 선임하기에는 비용과 준비 부담이 큽니다. | 내가 확인할 일과 전문가에게 물어야 할 일을 구분해서 보여줍니다. |
| 문서를 만든 뒤 서비스나 법률이 바뀌어도 언제 무엇을 고쳐야 할지 알기 어렵습니다. | 문서 버전과 변경 이력을 남기고, 영향을 받는 문서를 다시 확인할 수 있습니다. |

> **이 서비스의 출발점**
>
> 사용자에게 법률 질문지를 처음부터 쓰게 하지 않습니다. 사용자가 지정한 웹페이지·PRD·서비스 설명에서 시작합니다.

## 02. 사용자는 무엇을 하는가

1. 분석할 개별 웹페이지 URL, PRD 또는 서비스 설명처럼 이미 가진 자료를 전달합니다.
2. 서비스가 수집 정보, 이용 목적, 보관, 외부 제공·위탁처럼 문서에 필요한 사실 후보를 찾습니다.
3. 사용자는 확실한 사실을 확인하고, 잘못된 내용은 수정하며, 해당하지 않는 항목은 제외합니다.
4. 작성 시점에 사용자가 선택한 목표 국가의 법령·공식 지침을 조회하고, 확인된 공통 사실과 함께 참고해 선택한 국가의 문서만 각각 만듭니다.
5. 확인되지 않은 필수 정보가 없을 때 최종 승인하고, 시행일과 변경 이력을 남깁니다.

> **중요**
>
> 문서를 작성할 때 국가별 법령·공식 지침의 공개본을 조회해 출처와 기준일을 남깁니다. 법적 의미와 고객 서비스에 대한 적용 여부는 사람이 확인합니다.

## 03. 무엇을 제공하는가

MVP가 책임지는 결과물을 명확하게 제한합니다. 기본 서비스는 법률 자문이나 완전한 준법을 보증하는 상품이 아닙니다.

| 결과물 | 제공 내용 |
|---|---|
| 국가별 개인정보처리방침 | 지원하는 4개 관할 중 선택한 국가의 문서를 각각 독립 생성 |
| 검토 상태 표시 | 확인됨·추론됨·사람 확인 필요·해당 없음으로 구분 |
| 버전과 변경 이력 | 언제 무엇이 바뀌었는지 비교 |

### 구체적인 문서 이름과 제공 범위

| 제공 구분 | 구체적인 문서 이름 | 현재 범위 |
|---|---|---|
| 국가별 개인정보 문서 | 개인정보처리방침 | **MVP 제공** — 사용자가 선택한 국가별 독립 문서 생성 |
| 개인정보 고지·동의 문서 | 개인정보 수집·이용 동의서, 개인정보 제3자 제공 동의서, 개인정보 처리위탁 관련 고지, 개인정보 국외이전 관련 고지·동의서, 마케팅 정보 수신 동의서, 청소년 관련 동의서, 민감정보·고유식별정보 관련 동의서 | **출시 후 검토** — 화면별 입력 정보와 국가별 고지·동의 요건을 별도로 정의한 뒤 구현 |
| 위치·쿠키 관련 문서 | 위치정보 이용약관·동의서, 쿠키 관련 고지·정책 | **출시 후 검토** — 위치정보 처리와 쿠키·동의 관리 범위를 별도로 정의한 뒤 구현 |
| 계약 문서 | 서비스 이용약관 | **현재 구현 제외** — 개인정보 문서와 법적 목적이 다른 계약 문서이므로 별도 제품 범위로 결정 |

위 표는 문서 이름을 구체화한 것입니다. `출시 후 검토`와 `현재 구현 제외` 문서는 MVP 제공 결과물에 포함되지 않습니다.

### MVP가 자동 처리하지 않는 고위험 범위

MVP는 일반 웹·앱·커머스·SaaS의 개인정보처리방침 작성을 우선 지원합니다. 아래 유형 중 하나라도 해당하면 일반 SaaS용 자동 생성·발행 경로에서 제외하고, 판정 근거와 외부 전문가에게 확인할 사항을 안내합니다. 이는 해당 서비스가 위법하다는 판단이 아니라, 국가별 추가 의무와 위험평가가 필요한 범위를 제품이 자동 처리하지 않는 안전장치입니다.

| 고위험 처리 유형 | 해당 서비스·처리 예 |
|---|---|
| 아동·청소년 대상 | 아동·청소년이 주 이용자이거나 연령 확인·보호자 동의가 필요한 서비스 |
| 민감·특별관리 정보 | 건강·진료, 생체·유전·신경, 인종·신념·성생활, 범죄, 정밀 위치, 계정 접근정보를 핵심적으로 처리하는 서비스 |
| 중대한 자동화 결정 | 채용·보상, 금융·대출, 주거, 교육 기회, 의료 제공을 자동 판단하거나 프로파일링하는 서비스 |
| 지속적 감시·추적 | 얼굴·음성·행동 식별, 정밀 위치 추적, 공공장소·업무공간을 지속해서 관찰하는 서비스 |
| 판매·공유 중심 모델 | 개인정보 판매·교환, 데이터 브로커, 교차 맥락 맞춤광고가 핵심 수익모델인 서비스 |

## 04. 어디까지 소프트웨어가 하고, 어디부터 사람이 하는가

자동화하는 것은 ‘자료 정리와 작성 시점의 공식 출처 조회’이고, 사람이 책임지는 것은 ‘사실 확인과 법적 판단’입니다.

| 담당 | 하는 일 | 하지 않는 일 |
|---|---|---|
| 제품 | 자료 정리, 사실 후보 추출, 작성 시점 공식 출처 조회, 규칙 조합, 국가별 문서 생성·버전관리 | 법률 적용 여부를 최종 판단하거나 준법을 보증하지 않음 |
| 고객·운영자 | 서비스가 실제로 개인정보를 처리하는 방식을 확인하고 최종 발행 승인 | 확인하지 않은 사실을 자동 승인하지 않음 |
| 외부 법률 전문가 | 국가별 조항·생성 규칙, 면책 문구, 책임 범위와 법률 변경의 영향 검토 | 개별 고객 사실의 확인을 대신하지 않음 |

> **발행 원칙**
>
> 미확인 필수 정보나 서로 모순되는 사실이 남아 있으면 미리보기까지만 허용하고 공개 발행은 막습니다.

## 05. 기존 서비스와 무엇이 다른가

범용 해외 도구의 한국어 번역판이 아니라, 한국에서 해외로 나가는 창업자의 시작점을 다룹니다.

| 차별점 | 고객에게 의미하는 것 |
|---|---|
| 국내 출발점을 이해한다 | 국내 창업자가 가진 한국어 PRD와 서비스 자료에서 시작합니다. |
| 번역이 아니라 국가별 문서다 | 작성 시점의 국가별 법령·공식 지침과 관할별 요구사항을 각각 적용합니다. |
| 불확실성을 숨기지 않는다 | AI가 추론한 내용과 고객·전문가 확인이 필요한 내용을 분명히 구분합니다. |
| 생성 후에도 관리한다 | 서비스 사실이 바뀌거나 문서를 다시 작성할 때 출처를 다시 조회하고 새 버전과 변경 이력을 남깁니다. |

## 06. 현재 무엇이 확정됐고, 무엇이 남았는가

| 확정 | 출시 전 사람 확인 | 추후 논의 |
|---|---|---|
| 해외 진출 특화 포지셔닝 | 국가별 조항과 규칙의 법률 검수 | 가격과 사업모델 |
| 개인 예비창업자 포함 | 서비스 면책·책임 범위 | 변호사 검수 포함 유료 상품 |
| 초기 4개 관할 | 고객 데이터 보관·삭제 정책 | — |
| MVP에서 권한 분리 없음 | 작성 시점 공식 법령·지침 조회·이용 조건 | 다중 사용자 권한 분리 |
| 정량 성공 기준 미설정 | AI 공급업체·처리 지역·보유 정책 | 짧은 개인정보 고지문 |

## 07. 어느 나라부터 지원하는가

| 대한민국 | 캘리포니아 | 일본 | 싱가포르 |
|---|---|---|---|
| 기본 문서 | 미국 초기 범위 | 수요에 따라 우선순위 조정 | 수요에 따라 우선순위 조정 |

모두의창업 참여기업의 진출 희망국 수요를 확인해 일본과 싱가포르의 구현 순서를 조정할 수 있습니다. 사용자가 선택한 각 나라의 문서는 하나의 번역본이 아니라 독립 버전으로 관리합니다.

## 상세 원칙

| 구분 | 핵심 원칙 |
|---|---|
| 변경 대응 | 문서 작성·재작성 시 국가별 공식 법령·지침을 다시 조회해 출처 차이를 표시합니다. 적용 여부는 사람이 판단하며 검토 전에는 자동 수정·발행하지 않습니다. |
| 출시 게이트 | 초기 4개 관할의 조항·규칙 외부 검수, 필수 고객 정보 확인, 자체 개인정보처리방침·데이터 정책, 공식 자료·AI 공급업체 이용 조건이 필요합니다. |
| 미확정 | 가격·요금제, 외부 변호사 검수 상품, 후속 기능의 우선순위, 제품 성공 지표는 별도 의사결정으로 남아 있습니다. |
